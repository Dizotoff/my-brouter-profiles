### How to use:

- Open https://brouter.de/brouter-web/
- Click the wrench icon in the top-right panel.
- In the dialog that appears, click "Profile".
- Replace the existing profile code with the code from the selected repository file.
- Press Apply.
- Select a starting point and a destination.
- Explore different variations of the route via dropdown in the top left corner. Look for `Original`/`1st Alternative`/`2nd Alternative`/`3rd Alternative` options.
